# MarketHub — E-commerce Marketplace Demo

A responsive marketplace-style front-end project built with **HTML, CSS and vanilla JavaScript**.

## Features
- Responsive layout for desktop, tablet and mobile
- Product cards with category labels
- Search by product name/category
- Category filtering and price sorting
- Add-to-cart, quantity controls, remove items and subtotal
- Wishlist toggle
- Slide-out cart drawer and toast notifications

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. No build tools or package installation are required.

## Notes
This is a student portfolio demonstration. Checkout is a non-functional demo and no real payments or user accounts are processed. Product names, prices and emoji illustrations are sample data.

## Portfolio description
MarketHub is a front-end e-commerce marketplace prototype created to practise responsive web design and JavaScript DOM interactions. The project demonstrates product discovery, filtering, sorting, wishlist interactions and shopping-cart state management.
